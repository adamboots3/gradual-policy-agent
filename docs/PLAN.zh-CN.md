# 实施计划与当前范围

[English](PLAN.md) | [简体中文](PLAN.zh-CN.md) | [中文文档目录](README.zh-CN.md)

## 当前架构

LangChain 工具／模型适配器、有预算限制的 LangGraph 控制流程、FastAPI 和 React/TypeScript。
Agent 浏览 GitHub 政策目录并在线读取所选文件。
根据用户在 2026-10-24 的要求，已移除 SQLite 政策存储、FTS／向量检索、文档切片、Embedding 配置及初始化命令。

## 已确定的设计

- 仅提供 Web 访问，当前页面临时保存已完成问答。
- 使用前端最近 20 轮完整问答；仅在容量不足时裁剪最早的完整问答对，每次模型调用前重新检查。
- 提供三个工具：列出目录、读取指定原文文件／行范围、提交答案。
- LLM 按目录／名称选文件，必要时继续阅读。
- 每次提问固定一个不可变 GitHub commit，正文仅在本轮请求内存中保留。
- 引用取自本轮实际读取的准确原文行；不把历史回答当作政策证据，也不把来源真实当作语义正确。
- 来源、网络或限流失败时明确报错，不编造政策。
- 不包含已保存聊天历史、Embedding 服务、本地政策库、自动摘要、身份认证、管理后台或公开部署。
