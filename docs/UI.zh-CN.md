# Web 界面——临时对话

[English](UI.md) | [简体中文](UI.zh-CN.md) | [中文文档目录](README.zh-CN.md)

React/TypeScript Web 页面是唯一的对话入口；开发环境通过 Vite 代理 API，Compose 中使用 Nginx。
只有后端读取模型密钥。侧栏包含在线政策来源信息和新建对话按钮，
没有历史列表、已保存会话选择、恢复按钮或删除对话框。

- 已完成问答仅保存在当前页面 React 内存中；追问将问题／答案历史发送给 `/api/chat`，不发送已保存会话 ID。
- 新窗口／标签页为空；关闭、离开页面、刷新或新建对话会清空聊天。不使用 localStorage、sessionStorage 或 Cookie。
- 离开页面时取消浏览器请求并丢弃迟到的结果；请求状态和部分失败不会在服务端持久化。
- 建议问题只填入输入框；Enter 发送，Shift+Enter 换行，输入法组词时不提交。请求处理中禁止重复提交／新建对话。
- 失败的问题保持可编辑，只有已完成问答进入后续上下文。
- 选择引用会展示准确原文、章节、行范围和固定版本链接；回答／来源文本会转义，不作为 HTML 渲染。
- 模型配置、GitHub 来源失败和服务端错误均可见，并支持恢复操作。
- 来源卡片展示在线 GitHub 读取，不显示本地文档／切片数量。每个政策回答标识不可变来源 commit 和文件读取次数；引用面板展示准确原文行。问候可以没有来源 commit。

测试覆盖同窗口追问、独立挂载窗口、重新挂载清空、新对话清空、生成期间离开页面、重试、
防重复提交、来源展示、API 上下文限制和离线行为。展示持久化聊天历史的旧截图仅为历史记录，已被当前设计取代。

2026-10-24 的浏览器验收使用 1280×720 视口：真实中文申诉问题和追问成功，
第二个标签页为空，刷新清空两轮问答，关闭后重开也为空。输入框可用，引用摘录可见。
